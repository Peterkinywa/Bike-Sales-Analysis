# Bike-Sales-Analysis

## Overview
This Interactive dashboard analyzes customer demographics and buying behavior to understand factors influencing bike purchases. It provides interactive insights using Pivot Tables, Charts and Slicers.

## Dataset
The data includes customer information such as:
- Gender
- Marital Status
- Income
- Age & Age Brackets
- Education
- Occupation
- Number of Cars
- Children
- Commute Distance
- Region
- Bike Purchase Status (Yes/No)

## Key Insights Provided
- Income vs Purchase – Compares average income of buyers and non-buyers.
- Age Analysis – Identifies the most active purchasing age group.
- Commute Distance – Shows how travel distance affects buying behavior.
- Regional Performance – Highlights high-performing regions.

## Features
- Interactive slicers for filtering
- Pivot-based calculations
- Cleaned dataset
- Clear visual comparisons of buyers vs non-buyers
